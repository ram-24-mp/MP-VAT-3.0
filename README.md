# MP-VAT-3.0
A fork of [Joana Prata's MP-VAT 2.0]([https://app.geosamples.org/sample/igsn/10.58052/IEJDH0002](https://mpvat.wordpress.com/author/joanacorreiapratagmailcom/) tool for fluorescent analysis of microplastics. Version 3.0 has been modified to use manually set brightness thresholds (see line xxx) for particle detection rather than a Renyi Entropy algorithem for automatically setting detection thresholds. Additionally, 3.0 saves a copy of the particle mask generated by MP-VAT to the working directory.
